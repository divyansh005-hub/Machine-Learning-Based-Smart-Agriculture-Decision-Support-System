# Java Academic Prototype

This separate small Java OOP prototype addresses the guideline's Java implementation demonstration. The crop/fertilizer rules and yield calculation are illustrative only. This code does NOT load, call, or reproduce the trained Python Random Forest models and must not be presented as ML inference.

Compile and run:
```bash
cd src
javac *.java
java AgriSmartApp
```

OOP concepts: separation of concerns (menu, validation, service); composition (application uses validator/service); methods encapsulate demonstration logic. Ask faculty whether a Java client-to-Python API integration is expected; no such API is included.
